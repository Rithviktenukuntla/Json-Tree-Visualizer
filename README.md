# JSON Tree Visualizer

A modern web application for visualizing JSON data as interactive tree diagrams using React Flow.

## Features

### Mandatory Features
- ✅ JSON input with validation and error messages
- ✅ Tree visualization using React Flow
- ✅ Different colors for object, array, and primitive nodes
- ✅ Search functionality by JSON path
- ✅ Node highlighting and auto-centering for search results

### Optional Features
- ✅ Dark/Light mode toggle
- ✅ Clear/Reset button
- ✅ Copy JSON path on node click
- ✅ Download tree as PNG image
- ✅ Zoom controls (Zoom In/Out/Fit View)
- ✅ Pan and drag canvas navigation
- ✅ Node information display

## Tech Stack

- **Frontend**: React 18
- **Styling**: Tailwind CSS
- **Visualization**: React Flow
- **Build Tool**: Vite
- **Image Export**: html-to-image
